# Latent Transportable Interventions (LTI) 🚀

> **Zero-Shot Causal Direction Discovery via Differential Morphology and Phase-Space Hysteresis.**

Official repository for the preprint: *"Latent Transportable Interventions (LTI): One-Shot Causal Direction Discovery via Differential Morphology and Phase-Space Hysteresis"* by Houssam Rharbi.

## 📌 Overview
The LTI framework is a parameter-free, two-layer engine designed to break Markov Equivalence from a single passive bivariate time-series observation. It operates with mathematical certainty without requiring massive training datasets, making it ideal for Edge AI and critical autonomous systems.

* **Layer 1 (Derivative Correlation):** Exploits derivative sparsity to classify variables into Thermodynamic Roles ($E, F, Q$) and calculates asymmetric causal scores.
* **Layer 2 (Phase-Space Hysteresis):** Utilizes the Shoelace formula as a tie-breaker for structurally identical smooth signals, exploiting causal inertia.
